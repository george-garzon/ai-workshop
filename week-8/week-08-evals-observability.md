# Week 8 — Evals + Observability

## Goal
Be able to prove that your AI application works instead of judging it only by a few manual tests.

## Learn
- Evaluation datasets
- Golden answers
- Retrieval precision/recall
- Answer relevance
- Citation correctness
- LLM-as-a-judge
- Regression testing
- Prompt testing
- Tracing
- Latency
- Token usage
- Cost monitoring
- LangSmith concepts
- Arize Phoenix concepts
- OpenTelemetry concepts

## Build
Create a repeatable evaluation suite for Project #1.

Track real measurements such as:
```text
Retrieval accuracy
Citation accuracy
Answer relevance
Hallucination/error rate
Average latency
Input/output tokens
Average cost per query
```

Do not invent metrics. Generate them from actual evaluation runs.

## Portfolio Task
Put evaluation methodology and actual results in your README.

## Checkpoint
You should be able to answer:
> How do you know your AI system actually works?

Your answer should involve repeatable tests and metrics rather than intuition.
